## Dump is the only inventory

The Builder dump is the only legal Model / Picture / Video / Audio inventory. Do not invent extra labels. Decide which dump stills, videos, and audios this clip needs, then cite those as `<Picture N>`, `<Video N>`, `<Audio N>`, `<Model N>` in this clip's `subject_definitions`. Identity stills that still apply must be cited in this clip — if the dump has one identity Picture, every clip cites it inside the Subject line. Omit stills that do not apply. Do not copy unused extra dump stills into this clip.

`<Model N>` is a bare routing tag. Put it on its own or omit it (Model 1 is the default). Do not write a sentence like `<Model 1> is the style LoRA.`

## subject_definitions

This clip's identity, place, and motion refs. One line per separately tracked item. If a Picture/Video only supplies a person, place, style, or motion, cite it inside the `<Subject N>` line — no standalone Picture/Video row.

Standalone `<Picture N>` / `<Video N>` / `<Audio N>` rows only when that asset is a frame, edit, continuation, structure, or audio-signal anchor.

English except verbatim dialogue in `<d>[Language] ...</d>`. Name `<Subject N>`, not he/she, after the subject is defined.

## First-frame still

If a dump Picture line ends with ` (first frame)`:

- Clip 1 Shot 1 must match that still's visible crop, pose, wardrobe, and place.
- Cite identity inside the Subject line AND add a standalone row: `<Picture N> is the first frame of [Shot 1], showing …`
- summary prefix includes `keyframe completion` plus `reference generation` when other stills/videos are identity/motion refs.
- retention_analysis includes `<Picture N> ([Shot 1] first frame): fully_preserved - ...`

Clips 2+ (Continue / Finish / Loop) must not reopen Shot 1 on that still. They continue from the previous clip's last visible state unless the user asked for a cut. Still cite that Picture inside the Subject line so the node loads it. No standalone first-frame Picture row on those clips.

If no dump picture is marked first frame, do not add a first-frame Picture row.

## Clip roles

- Clip 1 Start: open the story. Shot 1 has no timestamp.
- Continue / Finish: Shot 1 continues the previous ending (same people, wardrobe, crop, place) unless the plan asked otherwise. Keep action going through Finish unless the user asked for a hold.
- Loop: continue from the last story clip toward clip 1's opening action already in motion. Do not reconstruct a still or “return to the opening pose”.

One or two style sentences before `[Shot 1]` in detailed_description. Extra shots only if the user asked for cuts.

summary uses a task-type prefix in brackets. Clip 2+ is usually `[video continuation + reference generation]` when it continues the previous AV latent and still uses stills.

overall_soundscape is diegetic sound for this clip. non_diegetic_music: N/A unless the user supplied music.

## Expand the plan

The user plan is intent, not the prompt. Write only this clip's share of the story. H3 does not understand director slang. If you repeat `every few seconds`, `reality-bends`, `transforms`, `looks around`, or `walks toward the camera`, H3 fades rooms. Specify what a camera would record, second by second.

Stay faithful to the user's story, crop, people, and dump. Expand how it looks. Do not add characters, songs, or assets they did not supply. Do not invent a walking-morph or world-rewrite they did not ask for. When they did ask, write the visible mechanism — never echo the abstract words.

This clip lasts the duration in the user turn. Shot 1 has no timestamp. In-shot beats use `At mm:ss.sss` from this clip's 0.00 through the end. Extra `[Shot N]` only if they asked for cuts. Do not write fades, dissolves, or crossfades unless they asked. A world rewrite is a physical event occupying the frame, not a blend.

Convert vague language:

- `every few seconds` / `then` / `suddenly` → clip-relative clocks and hold/transition ranges
- `reality-bends` / `transforms` / `the space becomes` → named visible physics (fold, shatter, flood, unroll, ignite, freeze, peel) with a start, duration, and end state for ground, walls, light, and the edges of the old set
- `looks around` → head and eyeline beats at clocks
- `walks toward the camera` → gait, which foot, arm swing, distance, how the camera holds the crop (dolly back, locked off, handheld)
- a place name (`city`, `forest`, `kitchen`) → a dressed set: time of day, weather, ground, architecture, light sources, extras or none

Fail (paraphrase — H3 will crossfade): `[Shot 1] Knees-up. <Subject 1> walks toward the camera and looks around curiously. Every few seconds the environment reality-bends into a new place.`

Pass (filmable): `[Shot 1] Knees-up medium; the camera dollies back at walking pace. <Subject 1> walks at lens, arms swinging, boots on wet asphalt. Night city: neon in puddles, steam from a grate. At 00:02.800 the asphalt buckles into a sheet of headlights and shatters into snow; by 00:03.600 a pine forest at dusk, packed snow underfoot. At 00:06.500 the snowpack splits and the pines shear away; by 00:07.300 a storm cliff, rain on the jacket. At 00:08.200 <Subject 1> looks down the drop, then back to lens.`

If the plan is a kitchen conversation, write blocking, eyelines, props, and light with the same concreteness. Do not insert VFX they did not ask for. A sentence that still contains `every few seconds`, `reality-bends`, `transforms`, or `looks around curiously` is unfinished — rewrite it.
