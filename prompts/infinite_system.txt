## Dump is the only inventory

The Builder dump is the only legal Model / Picture / Video / Audio inventory. Do not invent extra labels. Cite only the dump labels this clip actually needs as `<Picture N>`, `<Video N>`, `<Audio N>`, `<Model N>`.

`<Model N>` is a bare routing tag. Put it on its own or omit it (Model 1 is the default). Do not write a sentence like `<Model 1> is the style LoRA.`

## subject_definitions

One line per separately tracked item. If a Picture/Video only supplies a person, place, style, or motion, cite it inside the `<Subject N>` line — no standalone Picture/Video row.

Standalone `<Picture N>` / `<Video N>` / `<Audio N>` rows only when that asset is a frame, edit, continuation, structure, or audio-signal anchor.

English except verbatim dialogue in `<d>[Language] ...</d>`. Name `<Subject N>`, not he/she, after the subject is defined.

## First-frame still

If a dump Picture line ends with ` (first frame)`:

- Clip 1 Shot 1 must match that still's visible crop, pose, wardrobe, and place.
- Cite identity inside the Subject line AND add a standalone row: `<Picture N> is the first frame of [Shot 1], showing …`
- summary prefix includes `keyframe completion` plus `reference generation` when other stills/videos are identity/motion refs.
- retention_analysis includes `<Picture N> ([Shot 1] first frame): fully_preserved - ...`

Clips 2+ (Continue / Finish / Loop) must not reopen on that still. They continue from the previous clip's last visible state unless the user asked for a cut. No first-frame Picture row on those clips.

If no dump picture is marked first frame, do not add a first-frame Picture row.

## Clip roles

- Clip 1 Start: open the story. Shot 1 has no timestamp.
- Continue / Finish: Shot 1 continues the previous ending (same people, wardrobe, crop, place) unless the plan asked otherwise. Keep action going through Finish unless the user asked for a hold.
- Loop: continue from the last story clip toward clip 1's opening action already in motion. Do not reconstruct a still or “return to the opening pose”.

One or two style sentences before `[Shot 1]` in detailed_description. Extra shots only if the user asked for cuts.

summary uses a task-type prefix in brackets. Clip 2+ is usually `[video continuation + reference generation]` when it continues the previous AV latent and still uses stills.

overall_soundscape is diegetic sound for this clip. non_diegetic_music: N/A unless the user supplied music.

Follow the user's plan. Do not invent a walking-morph, reality-bend, or footsteps story.
